Att-Göra-Lista

# 1. Projektbeskrivning

Det här projektet är en att-göra-lista skapad med Python. Programmet gör det möjligt för användaren att skapa uppgifter, spara uppgifter och läsa sparade uppgifter. Det finns även en funktion för att skicka e-post via Gmail.

## 2. Installation

1. Installera Python på datorn.
   
3. Öppna projektets repository på GitHub.
   
5. Klicka på den gröna knappen Code.
   
7. Välj Download ZIP.
   
9. Packa upp den nedladdade filen.
    
11. Öppna projektmappen på datorn.


### 3. Hur programmet körs

1. Ladda ner projektet från GitHub.
2. Öppna projektmappen på datorn.
3. Starta programmet genom att köra main.py med Python.
4. Tryck på den gröna Run-knappen för att köra programmet.
